Signal → thesis → approved outreach.

every stage is a hard gate

Import

CSV in, originals kept forever

Preview → commit law: every raw row retained with an error class and a research task on failure. The system never auto-merges duplicates.

Discovery

Bounded collection

Fetches capped (2 MB, 15 s, 10 URLs/run), SSRF-guarded, content-hash snapshotted, stripped to an extraction allowlist. Injected script never survives.

Thesis engine

Explainable scoring

Five rubric dimensions — fit, trigger, timing, budget, access — roll up deterministically. Unknowns block qualification; nothing hides in a black box.

Honesty is enforced, not aspirational.

the rules tests fail on

Evidence law

Cite or hypothesize

Every material assertion references a claim ID or is explicitly framed "Hypothesis:". Uncited facts are rejected at write time (A05).

Isolation law

Deny by default

Postgres RLS with FORCE on all 29 tenant tables. Tests prove a foreign tenant reads zero rows — through a least-privilege role, not superuser.

Handoff law

Allowlisted envelopes

Versioned envelopes with payload hashes and disclosure scope. Only target, sector, stage and scores ever leave (A15).

The pilot gate is deliberately human: Alleadz ships with a hosted alpha, but first external outreach waits for a human decision on targets and message — built to make that decision auditable, not to make it for you.
